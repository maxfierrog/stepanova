# Decisions

Each file records one decision that shapes the project, so its reasoning is
not lost. Records are numbered in order (`NNNN-short-title.md`) and never
renumbered. A superseded record is not edited; a new record supersedes it and
links back.

Each record states its date and status, then three sections: **Context** (the
forces at play), **Decision** (what was chosen), and **Consequences** (what
follows, good and bad). Keep records short.
